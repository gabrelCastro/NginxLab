# Fidelity suite

`cases.ts` is the shared input for the real nginx recorder and the simulator tests. The committed JSON files are generated by `nginx:1.27-alpine` (nginx 1.27.5), so normal tests do not require Docker.

```bash
npm run fidelity:record
npm test
```

The recorder deliberately keeps only stable, observable fields: status, relevant headers and body. For `nginx -t`, the timestamped duplicate emitted by the Docker entrypoint is normalized to the stable nginx message.
